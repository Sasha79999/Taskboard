# TaskBoard Project

Наскрізний проєкт з курсу веб-розробки.

## Лабораторна робота №2: Перша сторінка

**Мета:** Підготовка середовища, створення базової HTML-сторінки, дослідження роботи браузера через DevTools.

### Виконані завдання:
- Налаштування VS Code та встановлення Live Server.
- Створення файлу `index.html` зі структурою HTML5.
- Додавання заголовків, абзаців, посилань та зображення з атрибутом `alt`.
- Аналіз HTTP-запитів у вкладці Network.
- Фіксація помилки 404 при невірному шляху до зображення.
- Дослідження роботи вкладок Elements та Console.

### Документація:
Детальний звіт з відповідями на питання та скріншотами:
[report.md](./report.md)

### Структура проєкту:
- `index.html` — головна сторінка.
- `images/` — директорія зображень.
- `screenshots/` — директорія зі скріншотами для звіту.
- `report.md` — звіт з лабораторної роботи.
- `README.md` — опис проєкту.
